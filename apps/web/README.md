# @connectx/web

ConnectX production frontend. Visual identity is locked to the HTML prototypes.

## Scripts

- `npm run dev` — Vite
- `npm run lint` — ESLint
- `npm run build` — `tsc -b` + Vite production build

## Environment

See `.env.example`. Use `VITE_API_BASE_URL` for FastAPI. Keep `VITE_USE_MOCKS=true` until Phase 15.
